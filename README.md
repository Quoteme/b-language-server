# b-language-server

A language server for classical B and Event-B, written in Kotlin, with ProB as its backend. It ships its own probcli
through the ProB Java Kernel.

## Documentation

The API documentation is generated by Dokka and published to GitHub Pages on every push to `master`:
[latest documentation deployment](../../deployments/github-pages).

## Usage

Clients communicate with the server either over stdio (start it with `--stdio`) or over a TCP socket. Without
`--stdio`, the server listens on a free port chosen by the operating system and prints it as `<port> is the port`.

## Capabilities

- **Diagnostics** on open and save:
  - classical B: ProB's parser and type checker, plus extended static checks, well-definedness checks and
    performance hints (see [Settings](#settings))
  - Event-B (Camille notation): Rodin's static checker, plus proof obligations generated as in Rodin and
    discharged or disproved (with a counterexample) by ProB's constraint solvers
- **Hover**: documentation of keywords and operators, and the types of identifiers; for Event-B also labels and
  proof obligations
- **Completion** of keywords, operators and the model's identifiers
- **Source actions**:
  - model check for deadlocks and invariant violations
  - discharge proof obligations with a longer timeout
  - list proof obligations
  - animate
- **Animation** of classical B and Event-B machines: execute operations/events (optionally with a predicate),
  step back and forward, go to a step, random steps, find a state satisfying a predicate, model check, restart
- **Visualisations** of the current animation state, as in ProB Tcl/Tk: graphical animation (`ANIMATION_FUNCTION`),
  VisB, dot graphs and tables

## Settings

The server requests the settings from the client:

```kotlin
// Runs ProB's extended static checks (linting) on top of type checking.
val strictChecks: Boolean = true
// Enables well-definedness checks, e.g. division by zero or function application outside the domain.
// See https://prob.hhu.de/w/index.php?title=Well-Definedness_Checking
val wdChecks: Boolean = true
// Reports hints about constructs that ProB may evaluate inefficiently.
val performanceHints: Boolean = true
// Path to the ProB installation to use; "DEFAULT" uses the probcli bundled with the ProB Java Kernel.
// See https://prob.hhu.de/w/index.php?title=ProB_Java_API
val probHome: String = "DEFAULT"
// Sends verbose log messages from the server to the client's output channel.
val debugMode: Boolean = true
// Time limit in milliseconds for discharging each Event-B proof obligation.
val poTimeout: Int = 1000
// Maximum number of states explored by the model checker.
val modelCheckStates: Int = 100000
```

`probHome` must point to the directory of a ProB installation, not to `probcli.sh`. A probcli version other than
the one used by the ProB Java Kernel can cause uncaught errors.
