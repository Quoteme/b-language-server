=== #7bf5c165a021
```eventb
s ∘ r
```

---

**Relational backward composition** · Typed as `circ`.

An element x is related by r ;S to an element y if there is an element z such that r relates x to z and S relates z to y.

s ∘ r can be written as an alternative to r ;s. This reflects the fact that f(g(x)) = (f ∘ g)(x) holds for two functions f and g.

The relational overwrite r s is equal to r except all entries in r whose first element is in the domain of s are replaced by the corresponding entries in s.

The parallel product r | s relates a pair x ↦ y to a pair m ↦ n when r relates x to m and s relates y to n.

If a relation r relates an element x to y and s relates x to z, the direct product r ⊗ s relates x to the pair y ↦ z.

The inverse relation r^-1 relates an element x to y if the original relation r relates y to x.

*Definition:* r ∘ s ≙ s ;r  
*Type:* r ∘ s ∈ ℙ(γ × α) with r ∈ ℙ(α × β) and s ∈ ℙ(β × γ)  
*Well-definedness:* L(r ∘ s) ≙ L(r) ∧ L(s)

**Example**
```eventb
{2 ↦ 3} ∘ {1 ↦ 2} = {1 ↦ 3}
```

[Rodin Handbook, 3.3.5.5 Operations on relations](https://www3.hhu.de/stups/handbook/rodin/current/html/relations.html#operations_on_relations)

=== #8e0edbfd1ea2
```eventb
⋂x·P ∣ E
```

---

**Quantified intersection** · Typed as `INTER`.

⋃ x1…,xn · P | E is the union of all values of E for valuations of the identifiers x1…,xn that fulfill the predicate P. The types of x1,…,xn must be inferable by P.

Analogously is ⋂ x1…,xn · P | E the intersection of all values of E for valuations of the identifiers x1…,xn that fulfill the predicate P.

Like set comprehensions (3.3.4.1), the quantified union and intersection have a short form where the free variables of the expression are quantified implicitly: ⋃ E | P and ⋂ E | P.

*Definition:* ⋂ x1…,xn · P | E = inter({x1…,xn · P | E}); ⋂ E | P = ⋂ Free(E) · P | E  
*Type:* (⋂ x1…,xn · P | E) ∈ ℙ(α); (⋂ E | P) ∈ ℙ(α)  
*Well-definedness:* L(⋂ x1…,xn · P | E) ≙ (∀ x1…,xn · L(P) ∧ (P ⇒ L(E))) ∧ ∃ x1…,xn · L(P); L(⋂ E | P) ≙ (∀ Free(E) · L(P) ∧ (P ⇒ L(E))) ∧ ∃ Free(E) · L(P)

**Example**
```eventb
(⋂x·x ∈ 1 ‥ 2 ∣ x ‥ 3) = 2 ‥ 3
```

[Rodin Handbook, 3.3.4.9 Quantified union and intersection](https://www3.hhu.de/stups/handbook/rodin/current/html/sets.html#a0000000392)

prj1 is a function that maps a pair to its first element. Likewise prj2 maps a pair to its second element.

id, prj1 and prj2 are generic definitions. Their type must be inferred from the environment.

*Definition:* id ≙ {x ↦ x | ⊤}  
*Type:* id ∈ ℙ(α × α) for an arbitrary type α .  
*Well-definedness:* L(id) ≙ ⊤

**Example**
```eventb
{1, 2} ◁ id = {1 ↦ 1, 2 ↦ 2}
```

---

**Integers** · Typed as `INT`.

The set of all integers is denoted by ℤ. It contains all elements of the type. The two subsets ℕ and ℕ1 contain all elements greater than or equal to 0 and 1 respectively. The range of numbers between a and b is denoted by a‥b.

*Definition:* ℕ ≙ {n | n ∈ ℤ ∧ n ≥ 0}; ℕ1 ≙ {n | n ∈ ℤ ∧ n ≥ 1}; a‥b ≙ {n | n ∈ ℤ ∧ a ≤ n ∧ n ≤ b}  
*Type:* ℤ ∈ ℙ(ℤ); ℕ ∈ ℙ(ℤ); ℕ1 ∈ ℙ(ℤ)  
*Well-definedness:* L(ℤ) ≙ ⊤

**Example**
```eventb
−1 ∈ ℤ
```

**Boolean true** · Typed as `TRUE`.

BOOL is a pre-defined carrier set that contains the constants TRUE and FALSE.

bool(P) denotes the Boolean value of a predicate P. If P is true, the expression is TRUE. If P is false, the expression is FALSE.

*Definition:* partition(BOOL,{TRUE},{FALSE}); bool(P) = TRUE ⇔ P  
*Type:* TRUE ∈ BOOL  
*Well-definedness:* L(TRUE) ≙ ⊤

**Example**
