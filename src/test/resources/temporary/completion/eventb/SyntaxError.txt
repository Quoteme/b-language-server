---

The dynamic part of a model: variables, invariants and the events that change the variables. A machine can refine one machine and see contexts.

**Example**
```eventb
machine Counter sees Limits
variables n
invariants
  @inv1 n ∈ 0 ‥ limit
events
  event INITIALISATION
    then @act1 n ≔ 0
  end
  event inc
    when @grd1 n < limit
    then @act1 n ≔ n + 1
  end
end
```

**Modulo** · Typed as `mod`.

These are the usual arithmetic operations.

*Definition:* amod b = c ≙ c ∈ 0‥b-1 ∧ ∃ k · k ∈ ℕ ∧ k · b + c = a  
*Type:* a mod b ∈ ℤ  
*Well-definedness:* L(amod b) ≙ L(a) ∧ L(b) ∧ a ≥ 0 ∧ b > 0

**Example**
```eventb

=== #ac1731c9ccb5

```

---

**Minimum** · Typed as `min`.

min(S) and max(S) denotes the smallest and largest number in the set of integers S respectively.

The minimum and maximum are only defined if such a number exists.

*Definition:* min(S) ∈ S ∧ (∀ x · x ∈ S ⇒ min(S) ≤ x)  
*Type:* min(S) ∈ ℤ and max(S) ∈ ℤ with S ∈ ℙ(ℤ).  
*Well-definedness:* L(min(S)) ≙ L(S) ∧ S ≠ ∅ ∧ ∃ b · ∀ x · x ∈ S ⇒ b ≤ x

**Example**
```eventb
min({3, 1, 2}) = 1
```

---

**Generalized intersection** · Typed as `inter`.

union(S) is the union of all elements of S. inter(S) is the intersection of all elements of S. The intersection is only defined for non-empty S.

*Definition:* inter(S) ≙ {x | ∀ s · s ∈ S ⇒ x ∈ s}  
*Type:* union(S) ∈ ℙ(α) and inter(S) ∈ ℙ(α) with S ∈ ℙ(ℙ(α)).  
*Well-definedness:* L(inter(S)) ≙ L(S) ∧ S ≠ ∅

**Example**
```eventb
inter({{1, 2}, {2, 3}}) = {2}
```

[Rodin Handbook, 3.3.4.8 Generalized union and intersection](https://www3.hhu.de/stups/handbook/rodin/current/html/sets.html#a0000000389)

=== #8e0edbfd1ea2
```eventb
⋂x·P ∣ E
```

---

**Quantified intersection** · Typed as `INTER`.

⋃ x1…,xn · P | E is the union of all values of E for valuations of the identifiers x1…,xn that fulfill the predicate P. The types of x1,…,xn must be inferable by P.

Analogously is ⋂ x1…,xn · P | E the intersection of all values of E for valuations of the identifiers x1…,xn that fulfill the predicate P.

Like set comprehensions (3.3.4.1), the quantified union and intersection have a short form where the free variables of the expression are quantified implicitly: ⋃ E | P and ⋂ E | P.

*Definition:* ⋂ x1…,xn · P | E = inter({x1…,xn · P | E}); ⋂ E | P = ⋂ Free(E) · P | E  
*Type:* (⋂ x1…,xn · P | E) ∈ ℙ(α); (⋂ E | P) ∈ ℙ(α)  
*Well-definedness:* L(⋂ x1…,xn · P | E) ≙ (∀ x1…,xn · L(P) ∧ (P ⇒ L(E))) ∧ ∃ x1…,xn · L(P); L(⋂ E | P) ≙ (∀ Free(E) · L(P) ∧ (P ⇒ L(E))) ∧ ∃ Free(E) · L(P)

**Example**
```eventb
(⋂x·x ∈ 1 ‥ 2 ∣ x ‥ 3) = 2 ‥ 3
```

[Rodin Handbook, 3.3.4.9 Quantified union and intersection](https://www3.hhu.de/stups/handbook/rodin/current/html/sets.html#a0000000392)

---

**Identity relation** · Typed as `id`.

id is the identity relation that maps every element to itself.

prj1 is a function that maps a pair to its first element. Likewise prj2 maps a pair to its second element.

id, prj1 and prj2 are generic definitions. Their type must be inferred from the environment.

*Definition:* id ≙ {x ↦ x | ⊤}  
*Type:* id ∈ ℙ(α × α) for an arbitrary type α .  
*Well-definedness:* L(id) ≙ ⊤

**Example**
```eventb
{1, 2} ◁ id = {1 ↦ 1, 2 ↦ 2}
```

=== #40828d8a76cc

---

**Integers** · Typed as `INT`.

The set of all integers is denoted by ℤ. It contains all elements of the type. The two subsets ℕ and ℕ1 contain all elements greater than or equal to 0 and 1 respectively. The range of numbers between a and b is denoted by a‥b.

*Definition:* ℕ ≙ {n | n ∈ ℤ ∧ n ≥ 0}; ℕ1 ≙ {n | n ∈ ℤ ∧ n ≥ 1}; a‥b ≙ {n | n ∈ ℤ ∧ a ≤ n ∧ n ≤ b}  
*Type:* ℤ ∈ ℙ(ℤ); ℕ ∈ ℙ(ℤ); ℕ1 ∈ ℙ(ℤ)  
*Well-definedness:* L(ℤ) ≙ ⊤

**Example**
```eventb
−1 ∈ ℤ
```
