---

**Subset** · Typed as `<:`.

S ⊆ T checks if S is a subset of T, i.e. if all elements of S occur in T. S ⊂ T checks if S is a subset of T and S does not equal T. S ⊈ T and S ⊄ T are the respective negated variants.

*Definition:* S ⊆ T ≙ ∀ e · e ∈ S ⇒ e ∈ T  
*Type:* S ⊆ T is a predicate with S ∈ ℙ(α), T ∈ ℙ(α)  
*Well-definedness:* L(S ⊆ T) ≙ L(S) ∧ L(T)

**Example**
```eventb
{1, 2} ⊆ {1, 2}
```

[Rodin Handbook, 3.3.4.3 Subsets](https://www3.hhu.de/stups/handbook/rodin/current/html/sets.html#subsets)

=== #45cc32e5725d
```eventb
S ↔ T
```

---

**Relations** · Typed as `<->`.

S ↔ T is the set of relations between the two sets S and T. A relation consists of pairs where the first element is of S and the second of T. S ↔ T is just an abbreviation for ℙ(S × T).

A total relation is a relation which relates each element of S to at least one element of T.

A surjective relation is a relation where there is at least one element of S for each element of T such that both are related.

*Definition:* S ↔ T ≙ ℙ(S × T); S ← ↔ T ≙ {r | r ∈ S ↔ T ∧ dom(r) = S}; S ↔ → T ≙ {r | r ∈ S ↔ T ∧ ran(r) = T}  
*Type:* S ↔ T ∈ ℙ(ℙ(α × β))  
*Well-definedness:* L(S ↔ T) ≙ L(S) ∧ L(T)

**Example**
```eventb
{1 ↦ 2, 1 ↦ 3} ∈ {1} ↔ {2, 3}
```

[Rodin Handbook, 3.3.5.2 Relations](https://www3.hhu.de/stups/handbook/rodin/current/html/relations.html#a0000000398)

=== #f6a950d2d69a
```eventb
x ≔ E
```

---

**Deterministic assignment** · Typed as `:=`.

x1,…,xn ≔ E1…,En assigns the expressions Ei to the variable xi, with i ∈ 1‥n. All xi must be distinct identifiers that refer to variables of the concrete machine.

There is a special form of the assignment which uses a relational overwrite:

x(F) ≔ E.

*Definition:* The before-after-predicate of x1,…,xn ≔ E1,…,En is; x(F) ≔ E ≙ x ≔ x {F ↦ E}  
*Type:* xi and Ei must have the same type: xi ∈ αi and Ei ∈ αi for i ∈ 1‥n.  
*Well-definedness:* L(x1,…,xn ≔ E1,…,En) ≙ L(E1) ∧ … ∧ L(En); L(x(F) ≔ E) ≙ L(F) ∧ L(E)

**Example**
```eventb
@act1 n ≔ n + 1
@act2 f(1) ≔ 2
```

[Rodin Handbook, 3.3.8.1 Deterministic Assignments](https://www3.hhu.de/stups/handbook/rodin/current/html/assignments.html#deterministic_assignments)

---

**Set subtraction** · Typed as `\`.

The union S ∪ T denotes the set that contains all elements that are in S or T. The intersection S ∩ T denotes the set that contains all elements that are in both S and T. The set subtraction or set difference S ∖ T denotes all elements that are in S but not in T.

*Definition:* S ∖ T ≙ {x | x ∈ S ∧ x ∉ T}  
*Type:* S ∖ T ∈ ℙ(α) with S ∈ ℙ(α) and T ∈ ℙ(α)  
*Well-definedness:* L(S ∖ T) ≙ L(S) ∧ L(T)

**Example**
```eventb
{1, 2, 3} ∖ {2} = {1, 3}
```


---

**Range** · Typed as `ran`.

If r is a relation between the sets S and T, the domain dom(r) is the set of the elements of S that are related to at least one element of T by r.

Likewise the range ran(r) is the set of elements of T to which at least one element of S relates by r.

*Definition:* ran(r) ≙ {y | ∃ x · x ↦ y ∈ r}  
*Type:* dom(r) ∈ ℙ(α) and ran(r) ∈ ℙ(β) with r ∈ ℙ(α × β).  
*Well-definedness:* L(ran(r)) ≙ L(r)

**Example**
```eventb
ran({1 ↦ 2, 3 ↦ 4}) = {2, 4}
```

[Rodin Handbook, 3.3.5.3 Domain and Range](https://www3.hhu.de/stups/handbook/rodin/current/html/relations.html#domain_and_range)

**Pair** · Typed as `|->`.

E ↦ F denotes the pair whose first element is E and second element is F.

S × T denotes the set of pairs where the first element is a member of S and second element is a member of T.

*Definition:* S × T ≙ {x ↦ y | x ∈ S ∧ y ∈ T}  
*Type:* E ↦ F ∈ α × β with E ∈ α and F ∈ β .  
*Well-definedness:* L(E ↦ F) ≙ L(E) ∧ L(F)

**Example**
