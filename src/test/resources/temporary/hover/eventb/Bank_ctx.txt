=== #ad3fe1085c48
```eventb
E ∈ S
```

---

**Set membership** · Typed as `:`.

Checks if an expression E denotes an element of a set S.

*Definition:* E ∉ S ≙ ¬ (E ∈ S)  
*Type:* E ∈ S and E ∉ S are predicates with E ∈ α and S ∈ ℙ(α).  
*Well-definedness:* L(E ∈ S) ≙ L(E) ∧ L(S)

**Example**
```eventb
2 ∈ {1, 2, 3}
```

[Rodin Handbook, 3.3.2.5 Membership](https://www3.hhu.de/stups/handbook/rodin/current/html/predicates.html#membership)

=== #1e0528bc7f9b
```eventb
ℕ
```

---

**Natural numbers, starting with 0** · Typed as `NAT`.

The set of all integers is denoted by ℤ. It contains all elements of the type. The two subsets ℕ and ℕ1 contain all elements greater than or equal to 0 and 1 respectively. The range of numbers between a and b is denoted by a‥b.

*Definition:* ℕ ≙ {n | n ∈ ℤ ∧ n ≥ 0}; ℕ1 ≙ {n | n ∈ ℤ ∧ n ≥ 1}  
*Type:* ℕ ∈ ℙ(ℤ); ℕ1 ∈ ℙ(ℤ)  
*Well-definedness:* L(ℕ) ≙ ⊤; L(ℕ1) ≙ ⊤

**Example**
```eventb
0 ∈ ℕ ∧ −1 ∉ ℕ
```

[Rodin Handbook, 3.3.6.1 Sets of numbers](https://www3.hhu.de/stups/handbook/rodin/current/html/arithmetic.html#a0000000428)

=== #83e0a4536e8f
```eventb
finite(S)
```

---

**Finite set** · Typed as `finite`.

finite(S) is a predicate that states that S is a finite set. card(S) denotes the cardinality of S. The cardinality is only defined for finite sets.

*Definition:* finite(S) ≙ ∃ n,b · n ∈ ℕ ∧ b ∈ S ⤖ 1‥n  
*Type:* finite(S) is a predicate and card(S) ∈ ℤ with S ∈ ℙ(α), i.e. S must be a set.  
*Well-definedness:* L(finite(S)) ≙ L(S); L(card(S)) ≙ L(S) ∧ finite(S)

**Example**
```eventb
finite(1 ‥ 10)
```

[Rodin Handbook, 3.3.4.6 Finite sets](https://www3.hhu.de/stups/handbook/rodin/current/html/sets.html#a0000000383)
