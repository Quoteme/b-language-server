Checks if an expression E denotes an element of a set S.

*Definition:* E ∉ S ≙ ¬ (E ∈ S)  
*Type:* E ∈ S and E ∉ S are predicates with E ∈ α and S ∈ ℙ(α).

=== #391107cfe11a
```eventb
a ‥ b
```

---

**Range of numbers** · Typed as `..`.

The set of all integers is denoted by ℤ. It contains all elements of the type. The two subsets ℕ and ℕ1 contain all elements greater than or equal to 0 and 1 respectively. The range of numbers between a and b is denoted by a‥b.

*Definition:* a‥b ≙ {n | n ∈ ℤ ∧ a ≤ n ∧ n ≤ b}  
*Type:* a‥b ∈ ℙ(ℤ) with a ∈ ℤ and b ∈ ℤ  
*Well-definedness:* L(a‥b) ≙ L(a) ∧ L(b)

**Example**
```eventb
2 ‥ 4 = {2, 3, 4}
```

=== #f6a950d2d69a
```eventb
x ≔ E
```

---

**Deterministic assignment** · Typed as `:=`.

x1,…,xn ≔ E1…,En assigns the expressions Ei to the variable xi, with i ∈ 1‥n. All xi must be distinct identifiers that refer to variables of the concrete machine.

There is a special form of the assignment which uses a relational overwrite:

x(F) ≔ E.

*Definition:* The before-after-predicate of x1,…,xn ≔ E1,…,En is; x(F) ≔ E ≙ x ≔ x {F ↦ E}  
*Type:* xi and Ei must have the same type: xi ∈ αi and Ei ∈ αi for i ∈ 1‥n.  
*Well-definedness:* L(x1,…,xn ≔ E1,…,En) ≙ L(E1) ∧ … ∧ L(En); L(x(F) ≔ E) ≙ L(F) ∧ L(E)

**Example**
```eventb
@act1 n ≔ n + 1
@act2 f(1) ≔ 2
```

[Rodin Handbook, 3.3.8.1 Deterministic Assignments](https://www3.hhu.de/stups/handbook/rodin/current/html/assignments.html#deterministic_assignments)

=== #1f2a5716f906

---

**Universal quantification** · Typed as `!`.

The universal quantification ∀ x1,…,xn · P is true if P is satisfied for all possible values of x1…,xn. A usual pattern for quantification is ∀ x1…,xn · P1 ⇒ P2 where P1 is used to specify the types of the identifiers.

The existential quantification ∃ x1…,xn · P is true if a value of x1…,xn exists such that P is satisfied.

The types of all identifiers x1…,xn must be inferable by P. They can be referenced in P.

*Type:* The quantifiers and the P are predicates.  
*Well-definedness:* L(∀ x1…,xn · P) ≙ ∀ x1…,xn · L(P); L(∃ x1…,xn · P) ≙ ∀ x1…,xn · L(P)

**Example**
```eventb
∀x·x ∈ 1 ‥ 3 ⇒ x > 0
```

[Rodin Handbook, 3.3.2.3 Quantified predicates](https://www3.hhu.de/stups/handbook/rodin/current/html/predicates.html#quantified_predicates)

=== #f7455e125ace
```eventb
x :∣ Q
```

---

**Non-deterministic assignment with a before-after-predicate** · Typed as `:|`.

x1,…,xn :∣ Q assigns any value to the variables x1…,xn such that the the before-after-predicate Q is fulfilled. Each xi is an identifier that refers to a variable of the concrete machine.

All free identifiers in Q must be constants, concrete parameters, concrete variables or primed versions of the modified variables (x1’,…,xn’).

This is the most general form of assignment. All other assignments can be converted to this.

*Definition:* The before-after-predicate is Q.  
*Type:* Q is a predicate and all xi and x’i must have the same type: x1 ∈ αi and x’1 ∈ αi for i ∈ 1‥n.  
*Well-definedness:* L(x1,…,xn :∣ Q) ≙ ∀ x1’,…,xn’ · L(Q)

**Example**
```eventb
@act1 n :∣ n' > n
```
