=== #ad3fe1085c48
```eventb
E ∈ S
```

---

**Set membership** · Typed as `:`.

Checks if an expression E denotes an element of a set S.

*Definition:* E ∉ S ≙ ¬ (E ∈ S)  
*Type:* E ∈ S and E ∉ S are predicates with E ∈ α and S ∈ ℙ(α).  
*Well-definedness:* L(E ∈ S) ≙ L(E) ∧ L(S)

**Example**
```eventb
2 ∈ {1, 2, 3}
```

[Rodin Handbook, 3.3.2.5 Membership](https://www3.hhu.de/stups/handbook/rodin/current/html/predicates.html#membership)

=== #1e0528bc7f9b
```eventb
ℕ
```

---

**Natural numbers, starting with 0** · Typed as `NAT`.

The set of all integers is denoted by ℤ. It contains all elements of the type. The two subsets ℕ and ℕ1 contain all elements greater than or equal to 0 and 1 respectively. The range of numbers between a and b is denoted by a‥b.

*Definition:* ℕ ≙ {n | n ∈ ℤ ∧ n ≥ 0}; ℕ1 ≙ {n | n ∈ ℤ ∧ n ≥ 1}  
*Type:* ℕ ∈ ℙ(ℤ); ℕ1 ∈ ℙ(ℤ)  
*Well-definedness:* L(ℕ) ≙ ⊤; L(ℕ1) ≙ ⊤

**Example**
```eventb
0 ∈ ℕ ∧ −1 ∉ ℕ
```

[Rodin Handbook, 3.3.6.1 Sets of numbers](https://www3.hhu.de/stups/handbook/rodin/current/html/arithmetic.html#a0000000428)

=== #00e4d44083b3
```eventb
P ∧ Q
```

---

**Conjunction** · Typed as `&`.

These are the usual logical operators.

*Definition:* P ∧ Q  
*Type:* All arguments are predicates.  
*Well-definedness:* Please note that the operators ∧ and ∨ are not commutative because their well-definedness conditions distinguish between the first and second argument. Therefore, if their arguments have well-definedness conditions, the order matters. For example, x ≠ 0 ∧ y ÷ x = 3 is always well-defined, but y ÷ x = 3 ∧ x ≠ 0 still has the well-definedness condition x ≠ 0.; L(P ∧ Q) ≙ L(P) ∧ (P ⇒ L(Q)); L(P ∨ Q) ≙ L(P) ∧ (P ∨ L(Q))

**Example**
```eventb
1 < 2 ∧ 2 < 3
```

[Rodin Handbook, 3.3.2.2 Logical operators](https://www3.hhu.de/stups/handbook/rodin/current/html/predicates.html#a0000000349)

=== #f6a950d2d69a
```eventb
x ≔ E
```

---

**Deterministic assignment** · Typed as `:=`.

x1,…,xn ≔ E1…,En assigns the expressions Ei to the variable xi, with i ∈ 1‥n. All xi must be distinct identifiers that refer to variables of the concrete machine.

There is a special form of the assignment which uses a relational overwrite:

x(F) ≔ E.

*Definition:* The before-after-predicate of x1,…,xn ≔ E1,…,En is; x(F) ≔ E ≙ x ≔ x {F ↦ E}  
*Type:* xi and Ei must have the same type: xi ∈ αi and Ei ∈ αi for i ∈ 1‥n.  
*Well-definedness:* L(x1,…,xn ≔ E1,…,En) ≙ L(E1) ∧ … ∧ L(En); L(x(F) ≔ E) ≙ L(F) ∧ L(E)

**Example**
```eventb
@act1 n ≔ n + 1
@act2 f(1) ≔ 2
```

[Rodin Handbook, 3.3.8.1 Deterministic Assignments](https://www3.hhu.de/stups/handbook/rodin/current/html/assignments.html#deterministic_assignments)
